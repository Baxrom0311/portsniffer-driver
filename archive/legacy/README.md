# Legacy Archive

Bu papka reference uchun saqlangan eski snapshotlar va artefaktlardan iborat.

## Nima uchun archive qilindi

- Workspace ichida bir xil loyihaning juda ko'p nusxasi yig'ilib qolgan edi
- Qaysi papka active ekanini tushunish qiyinlashgan edi
- Endi development faqat `variants/single-port` va `variants/multi-port` ichida olib boriladi

## Qoida

- `archive/legacy` ichidagi kod canonical emas
- Bu yerdagi fayllar faqat tarix, taqqoslash va ma'lumot uchun
- Active o'zgarishlar shu papkaga emas, `variants/` ichidagi variantlarga yoziladi
